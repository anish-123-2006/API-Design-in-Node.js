## What are sub-routers in Express, and how are they typically organized?

Click to reveal answer
Sub-routers are individual routers for specific resources that can be mounted onto a top-level router. They are typically created by importing the Router from Express and are organized by resource type (e.g., User Routes, Habit Routes).

## How do you create a sub-router in Express?

Click to reveal answer
```typescript
Import the Router named export from Express, then call it as a function: import { Router } from 'express' 
followed by const router = Router(). 
This creates a sub-router that can be mounted on a top-level router.
```

## What HTTP methods are typically used for user routes in a RESTful API?

Click to reveal answer
GET (retrieve users), PUT (update users), and DELETE (delete users) are commonly used. While POST can create users, authentication signup routes are typically separate from user CRUD operations.
